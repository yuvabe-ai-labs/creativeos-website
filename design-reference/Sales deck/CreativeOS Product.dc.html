04
Canvas workflow

The whole production is one readable graph.

Scripts, shots, prompts, and assets sit on one canvas as connected blocks. Anyone can see what fed an output. Nothing runs on its own.

Reel workflow

Script → shots → image prompts → start frames → motion prompts → clips.

Static-post workflow

Brief or trend → compositions → directions → generated image → targeted edits.

Shared inputs

Both draw on the same brand profile, moodboards, references and controls.

05
Generation and editing
Available now

Correct an image without restarting the work.

Remove, replace, or add an element — the rest is preserved. Every edit is a new attempt in the same history, never an overwrite. Video renders run in the background.

06
Review and approval
Available now

Approval stays human, and stays attached to a version.

Every attempt carries a maker and a reviewer. Approval attaches to the version — re-generating resets it. Approval marks work; it never triggers the next step.

Pending

The default state of a fresh attempt.

Approved

Signed off by a named reviewer, with the version it applies to.

Changes requested

Recorded with a note, so the correction survives.

07
Learning, history and cost

Every attempt is recorded with what produced it.

A version is written when a model runs — never on a keystroke. Raw output and human edit are kept separately; the difference is what makes the second project cheaper than the first.
